## 3. 맵 장애물 (신규 — EXT-A)

### 3.1 타일 타입 확장
```
0=벽  1=바닥  2=복도바닥(장애물 배치 금지 마킹)  3=기둥(파괴 불가)  4=크레이트(파괴 가능)
```

### 3.2 배치 규칙 (절차생성, 시드 결정론)
- 대상: 시작방 제외 모든 방(보스방은 M5-C에서 가장자리만).
- 기둥: 방당 1~3개, 1×1 또는 2×2. 크레이트: 방당 2~5개, 1×1.
- 금지 구역: 방 가장자리 2타일 마진 / 복도 통과 라인(타일 2) / 방 중심 3×3(제단·다운링크) / 기존 장애물과 8방 인접.
- 연결성: 마진+비인접+복도 라인 보존으로 우회 경로 항상 존재.

### 3.3 게임플레이
- 기둥: 시야/탄 차단 → 터릿전 엄폐 플레이. 적·플레이어·탄 모두 차단.
- 크레이트: 플레이어 탄 1발 또는 **대시 충돌**로 파괴(건전 테이블 슬램 오마주). 파괴 시 파티클 + 20% 확률 BITS 1. 적탄은 크레이트에 막혀 소멸(파괴는 플레이어만).
- 적탄·적 이동 모두 차단 → 전술 지형.

### 3.4 비주얼
- 기둥: 벽과 동일 회로 네온 외곽선(자동) + 어두운 채움.
- 크레이트: 앰버 박스(채움 + 밝은 테두리 + 대각선 X), 파괴 시 앰버 버스트.
