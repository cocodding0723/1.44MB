# 08 · 내러티브 / 스토리 설계 (Sephiria-inspired)

> 세피리아式 **캐릭터 주도 로그라이트 서사**(런 사이로 풀리는 메타 스토리 + 선택 가능한 주인공별 아크 + 다중 엔딩)를 NEON DESCENT에 얹는 설계.
> 본편(DESCENT)과 OVERCLOCK 모드 **둘 다에 걸치는 세계관 레이어**. 하드 제약(≤1.44MB · no-CRT · 에셋 0개 · 3×5 영문 폰트) 안에서 성립하는 방식만 채택.
> 추적: DESIGN.md(GDD) §26 확장 라인. 구현 시 v1.5로 등재. SDD(07)와 형제 문서.

## 0. 가장 먼저 — 하드 제약이 스토리에 거는 한계 (정직하게)

| 제약 | 스토리에 미치는 영향 | 설계 결론 |
|---|---|---|
| **폰트 3×5, 40글리프**(대문자 A-Z·0-9·`-.:/`) | 한글·소문자·`!?,'` 없음 | **서사 텍스트는 영문**. 폰트에 소문자26+구두점 약간(+~64B) 추가해 가독성 확보 권장 |
| **한글 미지원** | 한국어 내러티브 = 수천 한글 글리프(거대) | 한글은 **미채택**(또는 사용 음절만 추린 서브셋 폰트 = 별도 스트레치). **영문 + 기계어투 톤**으로 정공법 |
| **문자열 = 초기화 데이터**(.bss 아님) | 텍스트가 파일 크기에 직접 가산 | 현재 79KB, 캡까지 **~1.39MB 여유** → 텍스트 수십 KB는 **무관**. 진짜 비용은 바이트가 아니라 *집필*과 *세이브 시스템* |
| **에셋 0개** | 캐릭터 초상화 비트맵 불가 | **절차 벡터 시질(sigil)** = 도형·글리프로 캐릭터 상징. 기존 프리미티브 재활용 |
| **결정론·no-CRT** | — | 텍스트 트리거는 시드/진행 기반, 메타 저장은 Win32 `CreateFile`(rules/20 스트레치 허용) |

> **핵심:** 바이트는 문제가 아니다. "기계 속 영문 시스템 로그/교신" 톤이 오히려 세계관과 폰트에 완벽히 들어맞는다. 세피리아의 *분위기*(파편적 서사·캐릭터 아크·해금형 lore)는 가능, *방식*(한글 대사·초상화)은 톤을 바꿔 대체한다.

## 1. 세계관 (Premise & World)

**THE MAINFRAME** — 한 행성급 기계지성이 "**THE ROT**"(폭주 프로세스/부패)에 감염됐다. 시스템은 5개 계층으로 깊어지며, 그 명칭은 **이미 게임의 팰릿 5티어(§15)와 일치**한다:

```
LAYER 1-2  COOLANT  (냉각)   — 외곽, 차가운 진입부
LAYER 3-4  COMPUTE  (연산)   — 연산 코어, THE CORE 수호
LAYER 5-6  MEMORY   (메모리) — 기억 저장소, THE WARDEN 수호
LAYER 7-8  POWER    (전력)   — 전력망, 과부하 지대
LAYER 9+   KERNEL   (커널)   — 최심부, THE NEXUS와 부패한 CORE
```

> 팰릿 순환이 곧 **하강 서사의 시각적 챕터 구분**이 된다 — 새 시스템 0비용.

**플레이어 = REVENANT(잔존자).** 시스템에서 *삭제된* 한 의식의 아카이브 파편. 부패가 삭제 로그를 깨우며 다시 인스턴스화됐다. 너는 KERNEL의 부패한 CORE에 도달해 **PURGE**(정화)하라는 명령을 받는다 — 그러나 *누가* 너를 삭제했고 *왜* 깨웠는지는 하강하며 드러난다.

**ECHO** — 파편화된 관리자 AI. 무선 교신으로 안내하지만 손상돼 신뢰할 수 없는 화자(unreliable narrator). 깊어질수록 ECHO의 진술과 코덱스가 어긋난다.

## 2. 캐릭터 (절차 시질 + 영문 보이스)

> 초상화 대신 **도형 시질**: 각 캐릭터를 고유 벡터 엠블럼(회전 링·다각형·글리프 조합)으로 표현. 교신 시 화면 모서리에 시질 + 이름 + 텍스트.

| 캐릭터 | 역할 | 시질 모티프 | 톤 |
|---|---|---|---|
| **REVENANT** | 주인공(기본) | 흰 다이아 코어 + 깨진 링 | 과묵, 단편 기억 |
| **ECHO** | 안내 AI | 점멸 삼각 + 노이즈 | 친절→불안정, 신뢰 불가 |
| **THE CORE** | 보스1 | 맥동 구체 | 방화벽 수문장, 의무적 |
| **THE WARDEN** | 보스2 | 회전 프레임 | 보안 구속자, 냉혹 |
| **THE NEXUS** | 보스3 | 노드망 | 네트워크 집합지성, 다성(多聲) |
| **THE ROT** | 흑막 | 형태 없는 글리치 | 부패 그 자체, 유혹 |

- 보스는 단순 적이 아니라 **부패한 서브시스템 인격** — 조우 시 인트로 대사, 페이즈 전환·처치 시 단편 대사. 기존 보스 등장/페이즈 훅(`boss_update` 페이즈 전환 지점)에 텍스트 트리거만 추가.

## 3. 페르소나 (Sephiria式 선택 주인공 — 해금형)

세피리아의 캐릭터 주도 구조 차용: **시작 시 페르소나 선택**. 각 페르소나 = 고유 시작 무기 + 개인 lore 파편 + 고유 엔딩 비트. (OVERCLOCK·DESCENT 공유.)

| 페르소나 | 플레이 정체성 | 개인 서사 훅 | 해금 |
|---|---|---|---|
| **REVENANT** | 균형(기본총) | 왜 삭제됐는가 | 기본 |
| **DAEMON** | 공격/글래스(고화력) | 삭제를 *즐기는* 폭주 백신 | L5 도달 |
| **SENTINEL** | 방어/오비탈 | 주인을 잃은 수호 프로세스 | 보스2 격파 |
| **GHOST** | 기동/블링크 특화 | 업로드에 실패한 사용자의 잔향 | 엔딩 1회 |

- 각 페르소나는 자기 시점의 교신/코덱스 변주를 가짐 → **리플레이 동기**(세피리아 핵심 루프).
- MVP는 REVENANT 1종 + 서사 골격. 페르소나 확장은 Phase 2.

## 4. 전달 방식 (Delivery — 전부 텍스트/시질, 에셋 0)

1. **레이어 진입 교신(Transmission):** 새 레이어 첫 진입 시 화면 하단에 ECHO/시질 + 2~3줄 영문 교신(타이핑 연출). DESCENT의 레이어 하강 지점(`descend()`)에 훅.
2. **보스 인트로/대사:** 보스방 진입·페이즈 전환·처치 시 보스 시질 + 1~2줄. 기존 보스 상태 훅 재활용.
3. **사망 에피타프(Epitaph):** 사망 화면(ST_OVER)에 도달 레이어 기반 단문("SIGNAL LOST IN MEMORY. THE ROT REMEMBERS YOU.") — 기존 게임오버 화면 확장.
4. **코덱스/lore 파편:** 처치·깊이·엘리트·시드 조건으로 **FRAGMENT** 해금. 일시정지/타이틀의 코덱스 화면에서 열람. 메타 진행의 핵심 수집물.
5. **엔딩:** 도달/조건별 다중 엔딩(아래 §6).
6. **환경 서사:** 방 이름·터미널 글리치 텍스트(미니맵/배경에 짧은 시스템 로그 스트링) — 분위기용 저비용.

> 모든 텍스트는 기존 `draw_text`(3×5) + 절차 시질. 신규 렌더 0, 신규 에셋 0.

## 5. 메타 내러티브 (런 사이 진행 — 로그라이트)

- **세이브 파일**(`%LOCALAPPDATA%\neondescent.dat` 확장, Win32 `CreateFile`): 해금 플래그(페르소나·코덱스·엔딩)·최고기록·*누적 부패도*.
- **누적 부패도(Corruption):** 사망/하강이 메타 카운터를 올리고, 임계마다 ECHO 교신과 코덱스가 *변형*된다 → "여러 번 죽을수록 진실에 가까워지는" 세피리아式 메타 서사.
- **반복 동기:** 페르소나 해금 → 새 시점 → 새 코덱스 → 엔딩 수집. 1회차로는 세계관이 다 안 드러난다(의도적 파편화).

---

## 6. 다중 엔딩 (조건 기반)

| 엔딩 | 조건(예) | 서사 |
|---|---|---|
| **PURGE** | CORE 격파(기본 클리어) | 부패를 지우지만 시스템도 함께 꺼진다 — 공허한 승리 |
| **MERGE** | 특정 코덱스 전부 + CORE 도달 | REVENANT가 새 커널이 된다 — 너가 곧 기계 |
| **ESCAPE** | GHOST 페르소나 + 조건 | 의식을 외부로 업로드, 기계를 떠난다 |
| **ROT** | 부패도 임계 초과 사망 누적 | 너 자신이 ROT였다는 폭로(배드/진엔딩 후보) |

- 엔딩은 짧은 영문 모놀로그 + 시질 연출. MVP는 PURGE 1종, 나머지는 Phase 2~3.

## 7. 샘플 스크립트 (톤 예시 — 영문 대문자, 기계 교신체)

```
[ENTER COOLANT // LAYER 1]
ECHO:  YOU ARE AWAKE. GOOD. THE COOLANT STILL HOLDS.
ECHO:  DESCEND. PURGE THE CORE. DO NOT TRUST THE WALLS.

[BOSS // THE WARDEN]
WARDEN: ARCHIVE 7741. YOU WERE DELETED FOR A REASON.
WARDEN: I AM THAT REASON.

[DEATH // LAYER 5 MEMORY]
SIGNAL LOST. MEMORY REWRITES YOU.
THE ROT REMEMBERS. ATTEMPT 0014.

[FRAGMENT 09 UNLOCKED]
"ECHO IS NOT THE ADMIN. ECHO IS WHAT IS LEFT OF YOU."
```

> 짧고 단정적인 시스템 로그체 = 폰트·세계관·바이트에 동시 최적. 세피리아의 정서적 파편성을 *기계 미니멀리즘*으로 번안.

## 8. 기술 설계

- **텍스트 저장:** 짧은 영문 리터럴 테이블(`g_lore[]`, `g_xmit[]`). 파일에 박히지만 수십 KB로 캡 무관. 긴 문단 금지(rules/10 정신: 짧게).
- **폰트 확장(권장):** `g_font[40]` → 소문자26 추가는 톤상 불요(대문자 유지). 구두점 `!?,'`만 +4글리프(+8B) 추가하면 표현력↑. (현재 `-.:/`만 있어 쉼표·느낌표 없음.)
- **트리거:** 레이어/보스/사망/조건 → 텍스트 인덱스. sim 결정론 영향 없음(표시 전용). 교신 중 sim 정지 옵션(가독성) 또는 비정지 오버레이.
- **세이브:** 12바이트 헤더 + 해금 비트필드 + 부패 카운터. 시작 시 로드, 해금/엔딩 시 저장. 손상 시 기본값 폴백.
- **연출:** 타이핑(글자 누적), 시질 회전/점멸 — 전부 `g_time`/`g_rngFx` 결정론·비주얼.

---

## 9. 모드별 적용

- **DESCENT(본편):** 정규 캠페인. 레이어 하강 = 서사 챕터(팰릿 티어), 보스 = 인격, 코덱스·엔딩의 주 무대. **서사 1순위 채널.**
- **OVERCLOCK:** "전투 시뮬레이션/스트레스 테스트" 프레이밍 — 같은 세계관·캐릭터를 빌리되 짧은 인트로/아웃트로 교신 + 코덱스 일부 공유. 호드 페이싱을 끊지 않게 교신 최소화.

## 13. 확정 사항 (Locked Decisions)

1. ✅ **언어 = 영문 대문자 기계 교신체.** 기존 3×5 폰트 유지 + 구두점 `!?,'` 등 소수 글리프 추가(+~8B). 한글은 미채택(필요 시 서브셋 폰트 별도 스트레치로 분리, 본 설계 범위 밖).
2. ✅ **서사 주 무대 = DESCENT(레이어 캠페인) 1순위.** 팰릿 5티어 = 챕터, 보스 = 인격, 코덱스·엔딩의 주 무대. OVERCLOCK은 세계관·캐릭터를 공유하되 교신 최소화(프레이밍 채널).
3. ✅ **메타 세이브 도입.** `%LOCALAPPDATA%\neondescent.dat` 확장 — 해금 플래그·누적 부패도·코덱스·최고기록. Win32 `CreateFile`(no-CRT, rules/20 스트레치). 12B magic 헤더 + 비트필드, 손상 시 폴백.
4. ⏳ **페르소나/엔딩 수 = 단계 분리.** N1 MVP는 REVENANT 1종 + PURGE 엔딩 1종 + 서사 골격. 페르소나(DAEMON/SENTINEL/GHOST)·엔딩(MERGE/ESCAPE/ROT)·부패도 변형 교신은 N2~N3.

## 14. 설계검토 결과 (design-reviewer red-team, 2026-06-14) — 대체로 견고, 갭 3건

> 내러티브는 OVERCLOCK과 달리 **본편 DESCENT에 얹으면 저위험**(레이어/보스/사망 훅이 이미 존재). 단 N1 착수 전 3개 갭을 닫을 것:
- **[HIGH] no-CRT 세이브**: memset 자작 확인(직렬화 OK). 단 **shell32 미링크 → LOCALAPPDATA는 `GetEnvironmentVariable("LOCALAPPDATA")`**(kernel32, 이미 링크). 세이브에 `version u32 + 길이 + CRC/체크섬` 3중검증, 쓰기는 temp→rename 원자적, 불일치 시 전량 기본값. 버전 마이그레이션(N1→N2 비트필드 확장) 규약 명시.
- **[HIGH] draw_text 다줄 미지원**: 현재 `draw_text`는 개행·소문자·`,!?'` 없음(샘플 §7의 쉼표·콜론 중 콜론만 가능). **`draw_text_multi`(개행 분할 + 타이핑 cutoff) 신규 헬퍼(+~0.3KB)** + 폰트에 `,!?'`(+~8B) 추가.
- **[MED] sim정지 매트릭스**: (모드 × 레이어/보스/레벨업/사망) 정지 여부 표 필요. DESCENT 하강=정지 OK, 보스 인트로=짧은 정지 or 비정지 오버레이 확정.
- 견고: 영문 교신체로 한글 글리프 폭발 회피(정직), 팰릿=챕터 매핑 코드 일치, explode_at류 결정론 안전.

**판정**: 본편 DESCENT 서사는 위 3갭만 닫으면 N1 착수 가능(OVERCLOCK 의존 없음).
