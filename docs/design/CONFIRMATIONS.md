# 디자인 컨펌 트래커 (rules/50)

비주얼 요소는 **PNG 목업 → 사용자 승인** 후 구현. `art-director`가 갱신.

| 요소 | 버전 | 상태 | 날짜 | 메모 |
|---|---|---|---|---|
| 맵/방 레이아웃 룩 | - | ⏳대기 | - | 던전 타일셋·벽 회로 룩 |
| 플레이어 실루엣 | - | ⏳대기 | - | 다이아/삼각 + 글로우 |
| 적 4종 실루엣 | - | ⏳대기 | - | 헌터/터릿/리코셰/포크 도형 |
| 보스 2종 | - | ⏳대기 | - | CORE(구체)·WARDEN(프레임) |
| UI 타이틀 | - | ⏳대기 | - | 로고+부제 |
| UI HUD | - | ⏳대기 | - | HP/LAYER/SCORE/BITS/미니맵 |
| UI 모듈선택 | - | ⏳대기 | - | 카드 3장 |
| UI 게임오버 | - | ⏳대기 | - | 점수 분해 |
| 팰릿 5티어 스와치 | - | ⏳대기 | - | 냉각/연산/메모리/전력/커널 |

> 상태: ⏳대기 / 🔁수정요청 / ✅승인. 모든 항목 ✅ 전까지 해당 비주얼 구현 보류.
