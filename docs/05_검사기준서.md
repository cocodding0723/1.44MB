# 05 · 검사 기준서 (Test Criteria / QA Bible)

> QA(`qa-playtester`)가 그대로 수행하는 검증 시나리오. 각 TC는 `03_기능명세서`의 F-기능과 매핑.
> 형식: **목표 / 선행조건(시드) / 단계(행동→기대) / 기대결과 / 엣지 / 합격기준**. 결정론(시드 고정) 전제.
> 심각도: CRIT(빌드·진행·용량 차단) > HIGH > MED > LOW.

## 공통 선행조건
- 빌드 성공(`build.bat`), exe 실행 가능, **용량 ≤ 1,474,560 bytes**(미충족 시 즉시 CRIT).
- 시드 고정 모드(디버그): 동일 시드로 재현. (없으면 관찰 기반 + 재현 절차 명시.)

## F-SIZE 🔴
- **TC-SIZE-01 (CRIT)** 목표: 최종 exe 용량 cap 이내.
  단계: `build.bat` → 출력 bytes 확인. 기대: ≤ 1,474,560. **초과 시 즉시 실격급 CRIT.**
- **TC-SIZE-02 (HIGH)** 목표: size 회귀 감시. 단계: 직전 이력 대비 Δ. 기대: 급증 시 원인 규명.

## F-MOV
- **TC-MOV-01 (HIGH)** WASD 이동. 단계: 각 방향+대각 입력→이동. 기대: 대각 속도=직선 속도(정규화), 최고 220px/s.
- **TC-MOV-02 (HIGH)** 대시. 단계: Space→순간 가속+무적. 기대: 0.14s 가속, 쿨 0.8s 중 재대시 불가, 무적 중 피격 무시.
- **TC-MOV-03 (MED)** 결정론. 단계: 시드 고정+동일 입력 2회. 기대: 동일 경로.

## F-WPN
- **TC-WPN-01 (HIGH)** 자동연사. 단계: LMB 홀드. 기대: 0.20s 간격 발사, 마우스 방향.
- **TC-WPN-02 (MED)** 발사체 수명/사거리. 기대: 1.2s 후 소멸(~840px).
- **TC-WPN-03 (HIGH)** 데미지/처치. 단계: 헌터(HP20) 사격. 기대: ~0.4s(기본 DPS50) 처치.
- **TC-WPN-04 (MED)** 멀티샷 산포. 단계: 멀티샷 모듈 후 발사. 기대: 부채꼴 min(12°×n,60°), 발사체 n+1.

## F-MOD
- **TC-MOD-01 (HIGH)** 모듈방 3택1. 기대: 커먼 3장, sim 정지, 1·2·3/클릭 선택.
- **TC-MOD-02 (HIGH)** 효과 반영. 단계: 고출력 획득. 기대: 데미지 +25% 반영(수식).
- **TC-MOD-03 (MED)** 시너지 추첨. 단계: 멀티샷 보유 후 카드. 기대: 관통/폭발/치명 가중 상승(통계적).
- **TC-MOD-04 (HIGH)** 상한. 기대: 멀티샷+6/치명100%/민첩1.8×/냉각0.2s 초과 안 됨.
- **TC-MOD-05 (HIGH)** degenerate 가드. 단계: 반사+관통. 기대: 탄 무한잔존 없음(수명 소모).
- **TC-MOD-06 (MED)** 신규 커먼(§26). 기대: 보복(저HP일수록 탄뎀↑, 풀피도 +5%/스택), 운동(이속일수록↑, 정지 +9%/전속 +22%/스택), 광란(사격 홀드 시 연사 램프, 캡 +1.5), 흡수(N킬마다 BITS 다발+광란 너지=FRENZY 보유 시만).
- **TC-MOD-07 (HIGH)** 신규 레어(§26) degenerate 가드. 기대: 글래스캐논(+60%/스택 캡2 + 피격당 +1뎀 → 무한생존 불가, 3스택 추첨 안 됨), 체인라이트닝(명중 시 인접 1체 단발 아크, 재귀 없음).
- **TC-MOD-08 (HIGH)** 신규 레어 CRYO·EXECUTE(§26 v1.6). 기대: CRYO=피격 적 속도 ×0.5, 0.5+0.3×stacks초 지속(갱신식·영구슬로우 없음, 냉기 링 큐), 4스택 추첨 캡. EXECUTE=적 HP<maxhp×(0.10+0.04×stacks) 즉사(보스 미적용), 3스택 추첨 캡. 레어 추첨 풀에 정상 등장(보스 보상), OC 레벨업엔 미등장(커먼만).

## QA 운영 규칙
- 모든 버그는 **재현(시드+단계)** 포함 보고. 재현 불가 시 명시.
- 마일스톤 게이트: **M4(MVP)는 CRIT/HIGH 0건**이어야 통과.
- 손맛(juice) 미달도 결함으로 취급(검사 대상). 비주얼은 승인 목업과 대조.
