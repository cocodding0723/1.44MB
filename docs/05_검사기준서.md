# 05 · 검사 기준서 (Test Criteria / QA Bible)

> QA(`qa-playtester`)가 그대로 수행하는 검증 시나리오. 각 TC는 `03_기능명세서`의 F-기능과 매핑.
> 형식: **목표 / 선행조건(시드) / 단계(행동→기대) / 기대결과 / 엣지 / 합격기준**. 결정론(시드 고정) 전제.
> 심각도: CRIT(빌드·진행·용량 차단) > HIGH > MED > LOW.

## 공통 선행조건
- 빌드 성공(`build.bat`), exe 실행 가능, **용량 ≤ 1,474,560 bytes**(미충족 시 즉시 CRIT).
- 시드 고정 모드(디버그): 동일 시드로 재현. (없으면 관찰 기반 + 재현 절차 명시.)

---

## F-SIZE 🔴
- **TC-SIZE-01 (CRIT)** 목표: 최종 exe 용량 cap 이내.
  단계: `build.bat` → 출력 bytes 확인. 기대: ≤ 1,474,560. **초과 시 즉시 실격급 CRIT.**
- **TC-SIZE-02 (HIGH)** 목표: size 회귀 감시. 단계: 직전 이력 대비 Δ. 기대: 급증 시 원인 규명.

## F-MOV
- **TC-MOV-01 (HIGH)** WASD 이동. 단계: 각 방향+대각 입력→이동. 기대: 대각 속도=직선 속도(정규화), 최고 220px/s.
- **TC-MOV-02 (HIGH)** 대시. 단계: Space→순간 가속+무적. 기대: 0.14s 가속, 쿨 0.8s 중 재대시 불가, 무적 중 피격 무시.
- **TC-MOV-03 (MED)** 결정론. 단계: 시드 고정+동일 입력 2회. 기대: 동일 경로.

## F-WPN
- **TC-WPN-01 (HIGH)** 자동연사. 단계: LMB 홀드. 기대: 0.20s 간격 발사, 마우스 방향.
- **TC-WPN-02 (MED)** 발사체 수명/사거리. 기대: 1.2s 후 소멸(~840px).
- **TC-WPN-03 (HIGH)** 데미지/처치. 단계: 헌터(HP20) 사격. 기대: ~0.4s(기본 DPS50) 처치.
- **TC-WPN-04 (MED)** 멀티샷 산포. 단계: 멀티샷 모듈 후 발사. 기대: 부채꼴 min(12°×n,60°), 발사체 n+1.

## F-MOD
- **TC-MOD-01 (HIGH)** 모듈방 3택1. 기대: 커먼 3장, sim 정지, 1·2·3/클릭 선택.
- **TC-MOD-02 (HIGH)** 효과 반영. 단계: 고출력 획득. 기대: 데미지 +25% 반영(수식).
- **TC-MOD-03 (MED)** 시너지 추첨. 단계: 멀티샷 보유 후 카드. 기대: 관통/폭발/치명 가중 상승(통계적).
- **TC-MOD-04 (HIGH)** 상한. 기대: 멀티샷+6/치명100%/민첩1.8×/냉각0.2s 초과 안 됨.
- **TC-MOD-05 (HIGH)** degenerate 가드. 단계: 반사+관통. 기대: 탄 무한잔존 없음(수명 소모).
- **TC-MOD-06 (MED)** 신규 커먼(§26). 기대: 보복(저HP일수록 탄뎀↑, 풀피도 +5%/스택), 운동(이속일수록↑, 정지 +9%/전속 +22%/스택), 광란(사격 홀드 시 연사 램프, 캡 +1.5), 흡수(N킬마다 BITS 다발+광란 너지=FRENZY 보유 시만).
- **TC-MOD-07 (HIGH)** 신규 레어(§26) degenerate 가드. 기대: 글래스캐논(+60%/스택 캡2 + 피격당 +1뎀 → 무한생존 불가, 3스택 추첨 안 됨), 체인라이트닝(명중 시 인접 1체 단발 아크, 재귀 없음).

## F-ENM / F-ELT
- **TC-ENM-01 (HIGH)** 헌터 추격+분리. 기대: 직선 추격, 뭉침 없음.
- **TC-ENM-02 (HIGH)** 터릿 거리유지+발사. 기대: 300px 유지, 1.6s 발사+0.3s 텔레그래프.
- **TC-ENM-03 (MED)** 리코셰 반사. 기대: 벽 반사, 1.5s 방향 재설정.
- **TC-ENM-04 (HIGH)** 포크 분열. 단계: 포크 처치. 기대: Shard 2 생성, 재분열 없음.
- **TC-ENM-05 (MED)** 깊이 스케일. 기대: HP/속도가 §12 공식과 일치.
- **TC-ENM-06 (HIGH)** LANCER(L5, §26). 기대: 스토크(거리유지 슬라이드)→0.6s 예측선(t2 0.5~1.1)→520px/s 돌진 0.35s(벽 ±0.6r 2점 반사, 코너 진동 없음)→회복. 돌진속도 고정(Swift는 사이클만 단축).
- **TC-ENM-07 (HIGH)** WEAVER(L6, §26). 기대: 중거리 궤도 비행(벽 스터터 없음), 2.3s마다 기뢰(g_boom, 1.4s 신관, r90/2뎀, 풀 페이즈 경고링). 벽 근처 진동 없음.
- **TC-ELT-01 (HIGH)** 엘리트 등장. 기대: 확률 곡선·시각구분·BITS×3.
- **TC-ELT-02 (MED)** 어픽스 동작. 기대: 보호막/신속/폭발사망/자가분열/자성 각 효과.

## F-BOSS
- **TC-BOSS-01 (CRIT)** 보스 등장 로테이션. 단계: L3/L6/L9/L12 진입. 기대: **CORE/WARDEN/NEXUS/CORE** (3종 순환 (k-1)%3, v1.3 §26).
- **TC-BOSS-05 (HIGH)** NEXUS(L9). 기대: 3노드 회전 삼각 빔케이지(2뎀, halfw7 전 페이즈), ph2 노드당 8발 방사링(3.6s), ph3 수축(150→70, 12px/s)+본체 12발링(1.6s)+터릿 소환(최대2, 8s). 동일 틱 다중피격 없음(i-frame).
- **TC-BOSS-02 (HIGH)** 페이즈 전환. 기대: HP 66%/33%에서 패턴 변화.
- **TC-BOSS-03 (HIGH)** 보스방 잠금. 기대: 처치 전 이탈 불가.
- **TC-BOSS-04 (HIGH)** 보상. 기대: 처치 시 레어3택1+2HP+다운링크.

## F-DUN / F-ROOM
- **TC-DUN-01 (CRIT)** 연결성. 단계: 던전 생성. 기대: 모든 방 시작에서 도달 가능.
- **TC-DUN-02 (HIGH)** 결정론. 기대: 동일 시드=동일 레이아웃.
- **TC-DUN-03 (MED)** 특수방. 기대: 다운링크(최장거리)/모듈방/보스방 배치.
- **TC-ROOM-01 (HIGH)** 전투방 잠금. 기대: 진입 시 문 닫힘, 전멸 시 개방.
- **TC-ROOM-02 (MED)** 스폰. 기대: 가장자리·150px 이격·0.4s 텔레그래프.
- **TC-ROOM-03 (MED)** 클리어 보상. 기대: BITS 드롭+정화 플래시.

## F-DIFF / F-ECON
- **TC-DIFF-01 (MED)** 난이도 표 일치. 기대: 레이어별 적수/HP/속도/엘리트가 §12와 일치.
- **TC-ECON-01 (HIGH)** 점수 계산. 기대: 깊이×1000+킬×25+BITS×5+보스×500 정확.
- **TC-ECON-02 (MED)** BITS 흡인/수거. 기대: 자력 반경 흡인, 클리어 시 잔여 수거.
- **TC-ECON-03 (HIGH)** 회복 희소/자가피해. 기대: 바닥 체력드롭 없음, 폭발 자해 없음.

## F-CAM / F-ART / F-SND
- **TC-CAM-01 (HIGH)** juice. 단계: 피격/처치/폭발. 기대: 셰이크+히트스톱+파티클 발생.
- **TC-CAM-02 (MED)** 옵션. 기대: 셰이크/플래시 강도 0/50/100% 반영(광과민).
- **TC-ART-01 (HIGH)** 목업 일치. 기대: 화면이 **승인된 목업과 일치**(rules/50).
- **TC-ART-02 (MED)** 가독성. 기대: 적탄 vs 플레이어 색 분리, 팰릿 깊이%5 순환.
- **TC-SND-01 (MED)** SFX. 단계: 사격/피격/사망/픽업/대시/보스. 기대: 각 이벤트 SFX 재생.
- **TC-SND-02 (LOW)** 음소거. 기대: M 토글.

## F-STATE / F-HUD / F-CTL
- **TC-STATE-01 (HIGH)** 전이. 기대: TITLE→PLAYING→PAUSE→… §17 도식대로.
- **TC-STATE-02 (HIGH)** 일시정지. 기대: ESC 시 sim 정지, 재개 정상.
- **TC-STATE-03 (HIGH)** 재시작. 기대: GAMEOVER R→새 런 즉시.
- **TC-HUD-01 (MED)** HUD 일치. 기대: HP/LAYER/SCORE/BITS가 상태와 일치.
- **TC-HUD-02 (LOW)** 미니맵. 기대: 탐험/현재/특수 방 표시.
- **TC-CTL-01 (MED)** 입력. 기대: 전 키 매핑 동작, 커서=네온 십자선.

## F-SAVE (스트레치)
- **TC-SAVE-01 (LOW)** 최고기록. 단계: 종료 후 재실행. 기대: best_score/best_layer 유지.

## QA 운영 규칙
- 모든 버그는 **재현(시드+단계)** 포함 보고. 재현 불가 시 명시.
- 마일스톤 게이트: **M4(MVP)는 CRIT/HIGH 0건**이어야 통과.
- 손맛(juice) 미달도 결함으로 취급(검사 대상). 비주얼은 승인 목업과 대조.
