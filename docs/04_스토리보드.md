# 04 · 스토리보드 (Storyboard)

> 화면 흐름 + 코어 루프 비트 + 핵심 연출 순간. 비주얼은 **rules/50 컨펌 대상**(목업 PNG → `docs/design/`).
> ASCII는 배치 가이드, 최종 룩은 승인된 목업/게임 렌더 기준.

## 화면 전이 (state flow)
```
[TITLE] --click/space--> [PLAYING] --ESC--> [PAUSE] --ESC--> [PLAYING]
   ^                         |  |
   |                         |  +--전투방 진입--> (문잠금, PLAYING 유지)
   |                         +--모듈방/보스보상--> [UPGRADE_SELECT] --pick--> [PLAYING]
   +--ESC------------------ [GAMEOVER] <--HP0-- [PLAYING] --R--> 새 런
```

## SB-1 타이틀
- 화면: 큰 네온 "NEON DESCENT" + 부제 "PURGE THE MACHINE", 배경 파티클 부유, 최고기록.
- 연출: 로고 글로우 맥동. "CLICK / SPACE — DESCEND".
- → 입력 시 페이드/글리치 전환으로 LAYER 1 진입.

## SB-2 코어 루프 비트 시트 (한 레이어)
1. **진입** — 시작방(안전), 팰릿이 현재 티어 색. 플레이어 다이아가 다운링크에서 강하하듯 등장.
2. **탐험** — 복도 따라 이동, 카메라 추적+look-ahead. 미니맵에 방 노출.
3. **전투방 진입** — 문이 네온 배리어로 닫힘(사운드), 가장자리 0.4s 텔레그래프→적 등장.
4. **교전** — 마우스 조준 사격, 대시 회피. 피격 시 흰 플래시+적탄. 처치 시 파티클+히트스톱+BITS.
5. **클리어** — 전멸→문 개방+정화 플래시. BITS 흡인 수거.
6. **모듈방** — 제단에서 3택1 카드 부유(sim 정지). 선택 시 빌드 갱신 피드백.
7. **하강** — 다운링크 진입→글리치 전환→다음 레이어(팰릿 시프트, 난이도↑).
8. (3레이어마다) **보스** — 보스방 잠금, 페이즈 패턴, 처치 시 대형 폭발+레어 보상.
9. **사망** — HP0→화면 적색 펄스→GAMEOVER 점수 분해.

## SB-3 핵심 연출 순간 (juice moments)
- **첫 처치:** 8스파크+링, 0.03s 히트스톱 — "손맛" 각인.
- **대시 회피:** 잔상 트레일 + i-frame 깜빡임.
- **보스 P3 격노:** 적색 점멸 + 상시 약한 셰이크 + 압축 벽(WARDEN)/탄막 가속(CORE).
- **보스 처치:** 0.2s 히트스톱 + 화이트 플래시 + 대형 파티클 → 정적 → 레어 카드 강림.
- **레이어 전환:** 팰릿 색이 시안→마젠타→… 전환되며 분위기 환기.

## SB-4 UI 화면 (배치 — §18 목업 참조)
- **HUD:** 좌상 HP/LAYER, 우상 SCORE/BITS, 발밑 대시링, 우상 미니맵.
- **모듈선택:** 카드 3장(이름+효과), 1·2·3/클릭.
- **게임오버:** "SIGNAL LOST — LAYER n" + 점수 분해 + "R — DESCEND AGAIN".
