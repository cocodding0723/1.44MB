## 핵심 설계 결정 (코드에 없는 근거)
- **결정론 보호**: 비주얼 랜덤(셰이크·타이틀 파티클·사운드 지터)은 g_rngFx 전용, sim은 g_rng — QA 재현성 유지
- **시간왜곡 슬로모**: 고정 타임스텝 유지 위해 브레젠험 누적(0.3 가산→1 도달 시 1스텝)으로 0.3x 구현
- **크레이트는 플레이어만 파괴**(탄/대시), 적탄은 막힘 — 엄폐 전략성 의도
- **EMP 적탄 소거** = 엔터더건전 Blank 오마주(목표 게임필 직결)
- **보스 사망 시 잔여 적 일괄 정리** — 보상 화면 진입 클린업
- 내부 목표 64KB 대비 99%(65,024B) 도달 — 콘테스트 하드캡 1.44MB 대비 4.4%로 무관, 추가 기능 시 size 추정 필수

## 검증 도구
- `scripts/capture.ps1` / `qa-walk.ps1` / `qa-death.ps1`: PrintWindow(PW_RENDERFULLCONTENT)+PostMessage로 **포커스 안 뺏는** 게임 캡처/입력 주입 — QA·컨펌 자료 자동화. WndProc가 메시지 기반이라 백그라운드 입력 주입 가능

## 리뷰에서 잡은 버그 (재발 방지 교훈)
- **CRIT**: Edit로 hurt_player 꼬리를 바꿀 때 사망 판정 블록이 새로 추가한 boss_hit() 안으로 흡수됨 → 일반 레이어에서 사망 불가. **함수 꼬리 근처를 old_string으로 잡는 Edit는 닫는 중괄호 범위를 반드시 포함해 명시할 것.** 멀티에이전트 리뷰(적대적 검증)가 적발, 입력주입 플레이테스트로 수정 확인
- **HIGH**: g_kpress를 매 렌더 프레임 memset하면 히트스톱/슬로모/고주사율 프레임에서 sim이 못 본 입력이 유실 → 대시/EMP는 프레임 시작에 래치(g_wantDash/g_wantEmp)로 이관, sim 스텝 끝에서만 소거
