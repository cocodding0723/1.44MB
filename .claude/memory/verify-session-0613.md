# 검증 세션 (2026-06-13) — M4~M6+EXT 코드 적대적 리뷰 후 수정

워킹트리에 미커밋 상태이던 M4~M6+확장 코드를 ultracode Workflow(6차원 리뷰 23에이전트 + 적대적 검증)로 점검.
**CRIT/HIGH 0건** — 빌드·용량·no-CRT·메모리안전 클린. 이전 사망판정 CRIT은 수정 확인됨.
확정 MED 3 + LOW 7 중 9건 수정(BGM 드론은 GDD가 스트레치로 사전 승인 → 보류).

## 적용 수정 (src/game.c, 빌드 후 65536B 유지 = 64KB 블록 패딩 내 흡수)
1. **카메라 프레임레이트 의존(MED)**: `camera_update`의 0.12 lerp를 dt-스케일(`cf=7.2f*rdt`)로 → 60/144Hz 수렴 동일. sim 조준이 g_cam 읽으므로 프레임레이트별 탄도 차이 제거.
2. **코스메틱 RNG 오염(MED)**: `burst()`·머즐 파티클 산란을 g_rng→g_rngFx(fxsym)로. sim 시드 스트림에서 코스메틱 분리(결정론 규칙). **단 spawn_pickup 산란은 착지위치가 게임플레이(자력/획득)에 영향 → 의도적으로 g_rng 유지**.
3. **재생 레어 스택분할(MED)**: `25.0f/g_mod[M_REGEN]` → `25.0f` 고정. GDD §7 비스택 + §13 회복 희소성 복원.
4. g_rngFx 0 가드 추가(LOW, 1/2^31 멈춤 회피, g_rng 가드 미러).
5. 엘리트 어픽스 2개 중복붕괴(LOW): do-while 재추첨으로 b2≠b1 보장(§8.5 "중복 불가").
6. 자력 감속 오라 구현(LOW): AI루프에서 M_MAGNET 보유 시 반경 `80+20*stack` 내 적 spd*0.72(§7 미구현 서브효과).
7. 포크 샤드 벽내부 스폰(LOW): ±10px 오프셋 is_wall_w 체크, 막히면 부모 위치 폴백.
8. 게임오버 BEST 줄(LOW): SCORE 아래 `( BEST nnnnnn )` 추가(§18 목업 일치).

## 보류/근거
- 엘리트 오브 빈손 소비(LOW): 캡모듈 14중 최대4뿐이라 (4/14)^20≈5e-11 사실상 도달불가 → 미수정.
- BGM/정적드론(§16.4): GDD §689가 BGM을 스트레치(MVP 외)로 명시 → 비차단, 보류.
- 기각된 7건 중 주목: "레어 무제한 재추첨으로 회복 무한스택"은 기각됐으나(재생 스택분할 #3로 부분 완화), 레어 모듈 cap 부재는 설계상 의도일 수 있음 — 추후 밸런스 검토 여지.
