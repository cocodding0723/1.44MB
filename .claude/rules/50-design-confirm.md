# 50 — 디자인 이미지 컨펌 게이트

비주얼 디자인 요소는 **구현 전, PNG/JPG 이미지로 사용자 컨펌**을 받는다. 면책 없음.

## 대상 (컨펌 필수)
- 맵/방 레이아웃, 던전 타일셋 룩
- 캐릭터(플레이어)·적 4종·보스 2종 실루엣/도형
- UI 화면(타이틀/HUD/모듈선택/게임오버)
- 팰릿(레이어 5티어 색) — RGB 스와치 이미지

## 절차
1. `art-director`가 목업 이미지를 `docs/design/<element>-vN.png`로 생성.
2. 사용자에게 이미지로 제시 → **승인 / 수정요청**.
3. 수정요청 시 vN+1로 반복(루프). **승인 전 구현 착수 금지.**
4. 승인 결과를 `docs/design/CONFIRMATIONS.md`에 기록:
   `| 요소 | 버전 | 상태(✅승인/🔁수정/⏳대기) | 날짜 | 메모 |`

## 이미지 생성 방법 (에셋 파일 없이, 절차적)
네온 벡터라 도형 기반 → 코드로 생성 가능:
- **1순위:** `scripts/mockup.ps1` (PowerShell + System.Drawing) — 도형·글로우·팰릿을 PNG로 렌더(외부 의존 0).
- **2순위:** SVG 생성 → 변환(ImageMagick/Inkscape 있으면).
- **3순위(가장 정확):** 게임 자체 렌더러로 해당 화면을 그려 스크린샷(빌드 이후 단계).

## 게이트
- 훅 `design-confirm-gate.ps1`: 비주얼 요소 구현 커밋/머지 전 `CONFIRMATIONS.md`에 해당 요소 ✅ 있는지 확인, 없으면 경고/차단.
- `qa-playtester`는 실제 화면이 승인된 목업과 일치하는지도 점검.

## 원칙
- 텍스트 설명만으로 비주얼을 확정하지 않는다 — **반드시 눈으로 보고 컨펌.**
- 목업도 절차생성(에셋 파일 0개 원칙 유지).
